# Image-classification-based-on-heterogeneity
With applications in areas such as adaptive rendering, surveillance systems, and content management, automatic complex image classification based on complexity is an important area of focus in computer science. It has received considerable attention in recent years for its use within image compression processes. However, because traditional approaches to automatically classifying complex images use hand-crafted features and have computationally expensive processing pipelines, their generalisation capabilities are limited. The present work presents a unifying end-to-end deep learning framework (using only the VGG16 architecture) for producing binary classifications of images being complex vs. non-complex. Transfer Learning was employed using a pre-trained VGG16 feature extractor and modifying the classification head to train to the dataset used in this work. Extensive Data Augmentation was utilised and two (frozen-layer) stages of training were employed (i.e., training the pre-trained model using frozen layers first and then training the model with unfrozen layers to develop fine-tuning of the model). A Test-Time Augmentation (TTA) procedure further enhanced the system's ability to obtain stable predictions.
